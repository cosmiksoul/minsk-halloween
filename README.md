# Скелеты Минска · Хеллоуин

Пиксельный центр Минска, по которому гуляют случайные скелеты: встречаются, болтают, пьют пиво в барах с Зыбицкой и танцуют на площадях. У каждого есть имя, возраст, пол и место работы при жизни.

Чистый HTML + JavaScript без сборки: three.js подключается с CDN, данные зданий и улиц запечены из OpenStreetMap в `data/minsk.json`.

## Запуск локально

```bash
python -m http.server 8765
```

и открыть http://localhost:8765.

## Как устроено

- `src/city.js` — здания, дороги, вода, парки, деревья, тыквы, фонари из OSM-данных; окна считаются в шейдере.
- `src/post.js` — пиксельный пост-эффект: низкое разрешение, квантование цвета, дизеринг, обводка по глубине, небо с луной.
- `src/skeletons.js` — процедурные спрайты скелетов с костюмами.
- `src/bio.js` — архетипы, имена, работы, реплики.
- `src/sim.js` — граф улиц, прогулки, встречи, бары, танцы.
- `src/main.js` — камера, интерфейс, пузыри реплик.
