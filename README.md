# Хэллоуин в Минске

Пиксельный центр Минска в пределах первого кольца, по которому гуляют случайные скелеты: встречаются, болтают, пьют пиво в барах с Зыбицкой и танцуют на площадях. У каждого есть имя, возраст, пол и место работы при жизни.

Зелёные тыквы над крышами — бары, пабы и клубы из OpenStreetMap, тыквы с оранжевой обводкой — клубы и площадки с афишей. Клик по тыкве открывает карточку заведения: адрес, часы, рейтинг в скелетах (считается по заходам в симуляции) и анонсы из афиши. Справа лента: «Места», «Афиша» и «Свой скелет» — можно создать скелета с именем, возрастом и занятием, он сохранится в браузере, а кнопка «ссылка» даст адрес, по которому его увидят друзья.

Чистый HTML + JavaScript без сборки: three.js подключается с CDN, данные зданий и улиц запечены из OpenStreetMap в `data/minsk.json`.

## Запуск локально

```bash
python -m http.server 8765
```

и открыть http://localhost:8765.

## Как устроено

- `src/city.js` — здания, дороги, вода, парки, деревья, тыквы, фонари из OSM-данных; окна считаются в шейдере.
- `src/post.js` — пиксельный пост-эффект: низкое разрешение, квантование цвета, дизеринг, обводка по глубине, небо с луной.
- `src/skeletons.js` — процедурные спрайты скелетов с костюмами.
- `src/bio.js` — архетипы, имена, работы, реплики.
- `src/sim.js` — граф улиц, прогулки, встречи, бары, танцы.
- `src/main.js` — камера, интерфейс, пузыри реплик.

- `src/venues.js` — заведения и привязка афиши.
- `data/events.json` — афиша: собирается вручную или скриптом с bezkassira.by и family.by, поле `updated` показывает дату сборки. Чтобы обновить, добавь события в массив `events`: `title`, `venue`, `addr`, `lat`/`lon` (если площадки нет в OSM), `date`, `time`, `price`, `age`, `kind` (party / concert / family), `desc`, `url`.

Данные карты © участники OpenStreetMap, ODbL. Афиша: bezkassira.by, family.by.
